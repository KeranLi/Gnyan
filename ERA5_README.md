## Illustration about the file name of each part

**For file name:**

*`P1000_P500_T_RH_SH_VcW_UcW_FCC_SRWC_1980_1989_year_d7_d14_d21_d28_t14_n37_e78_n26_e102`* means the ***`presure level`*** are ***`500 hPa`*** and ***`1000 hPa`***, containing variables of ***`Fraction of cloud cover (FCC), Relative humidity (RH), Specific humidity (SH), Specific rain water content (SRWC), Temperature (T), U-component of wind (UcW), V-component of wind (VcW).`***, daily span are  ***`7th (d7), 14th (d14), 21st (d21) and 28th (d28) in each month`***, hourly time is ***`14:00 in each day (t14)`*** and the subregion coordinates are ***`26 north degrees (n26) to 37 north degress (n37) and 78 east degrees (e78) to 102 east degrees (e102).`***

| Component                         | Explanation                                                                                                                                             |
|-----------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Pressure Level**                | `500 hPa` and `1000 hPa`                                                                                                                                 |
| **Variables**                     | **Fraction of cloud cover (FCC)**, **Relative humidity (RH)**, **Specific humidity (SH)**, **Specific rain water content (SRWC)**, **Temperature (T)**, **U-component of wind (UcW)**, **V-component of wind (VcW)**. |
| **Time Span**                     | Data collected from **1980 to 1989**                                                                                                                     |
| **Days of the Month**             | Data for the **7th, 14th, 21st, and 28th** of each month (`d7`, `d14`, `d21`, `d28`)                                                                     |
| **Hourly Time**                   | Data for **14:00 each day (t14)**                                                                                                                       |
| **Subregion Coordinates**         | Latitude: from **26°N to 37°N** and Longitude: from **78°E to 102°E**                                                                                  |
